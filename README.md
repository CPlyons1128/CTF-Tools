# Download CTF Tools 🚀

## Overview

This script automates the installation of essential Capture The Flag (CTF) tools for Kali Linux and other Debian-based systems. Whether you're competing in Hack The Box (HTB), NCL, or any major CTF, this script ensures you have the right tools at your fingertips.

You can choose to:

Install everything at once 🛠️

Select specific tools interactively 🔍

Install just one tool quickly ⚡

## Features

✅ Customizable installation – Choose which tools to install or install them all
✅ Automated setup – No need to manually configure each tool
✅ Optimized for Kali Linux – Runs smoothly with built-in dependencies
✅ Covers Web, Reverse Engineering, Forensics, OSINT, and more
✅ Regularly updated – Stay ahead with the latest CTF tools

## Installation & Usage

1️⃣ Clone the repository:
```bash
 git clone https://github.com/yourusername/CTF-Tools.git
 cd CTF-Tools
```

2️⃣ Make the script executable:
```bash
chmod +x install.sh
```

3️⃣ Run the script:
```bash
./install.sh
```

4️⃣ Follow the prompts to select your tools!

# 🚀 Kali Linux Terminal Customization Script
Supercharge your Kali Linux terminal with Zsh, Oh My Zsh, Powerlevel10k, auto-completion, and more!
This script customizes your Kali Linux terminal for efficiency, aesthetics, and enhanced usability by installing and configuring essential tools like Zsh, Powerlevel10k, syntax highlighting, fuzzy search, modern ls, and auto-completion.

## 🔥 Features
✅ Zsh + Oh My Zsh – A powerful, feature-rich shell replacement
✅ Powerlevel10k – A blazing-fast, highly customizable terminal prompt
✅ Syntax Highlighting & Autosuggestions – Boosts productivity with real-time command suggestions
✅ Auto-Completion – Streamlines command execution
✅ Fuzzy Finder (fzf) – Lightning-fast command search and navigation
✅ Modern ls (Exa) – Beautiful, color-enhanced directory listings with icons
✅ Enhanced cat (Bat) – Syntax-highlighted file previews for better readability
✅ Useful Aliases – Common commands simplified for efficiency
✅ Neofetch on Startup – Displays system info in style every time you open a terminal
✅ Fully Automated Setup – Just run the script and let it handle everything

## 📥 Installation & Usage
1️⃣ Clone the repository
```bash
git clone https://github.com/yourusername/CTF-Tools.git
cd CTF-Tools
```

2️⃣ Make the script executable
```bash
chmod +x customize-terminal.sh
```

3️⃣ Run the script
```bash
./customize-terminal.sh
```

4️⃣ Restart your terminal or run zsh
```bash
zsh
```

5️⃣ Follow the Powerlevel10k setup wizard and enjoy your fully customized terminal! 🎨💻
